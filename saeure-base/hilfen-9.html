So nutzen Sie die Hilfen: Versuchen Sie es erst allein. Öffnen Sie dann Hilfe 1, danach Hilfe 2. Die Lösung dient zur Kontrolle – vergleichen Sie sie mit Ihrer eigenen Antwort und verbessern Sie diese.

Aufgabe 1: Stoffmenge berechnen

Berechnen Sie n(H₃O⁺)!

Hilfe 1
n = c · V; Volumen in Liter umrechnen: 200 mL = 0,2 L.
Lösung (erst nach eigenem Versuch öffnen!)
n = 0,1 mol/L · 0,2 L = 0,02 mol

Aufgabe 2: Maßlösung herstellen

Berechnen Sie die Masse NaOH und beschreiben Sie die Herstellung!

Hilfe 1
Erst n = c · V, dann m = n · M.
Hilfe 2
Gerät für ein genaues Volumen: Messkolben mit Eichmarke.
Lösung (erst nach eigenem Versuch öffnen!)
n = 0,05 mol; m = 2,0 g. Einwiegen, im Messkolben lösen, abkühlen, bis zur Marke auffüllen.

Aufgabe 3: Titration auswerten

Berechnen Sie c(Salzsäure)!

Hilfe 1
Rechenschritte stehen im Kasten „So rechnen Sie“.
Hilfe 2
n(OH⁻) = 0,1 mol/L · 0,016 L
Lösung (erst nach eigenem Versuch öffnen!)
c(HCl) = 0,0016 mol / 0,020 L = 0,08 mol/L

Aufgabe 4: Entsorgung

Berechnen Sie das Volumen Natronlauge!

Hilfe 1
n(H₃O⁺) im Abfall = n(OH⁻), die gebraucht werden. Dann V = n / c.
Lösung (erst nach eigenem Versuch öffnen!)
n = 0,16 mol; V = 0,16 L = 160 mL

Aufgabe 5 (★ Wahl): Schwefelsäure titrieren

Berechnen Sie c(H₂SO₄)!

Hilfe 1
Jedes H₂SO₄-Molekül liefert zwei Oxonium-Ionen: n(H₂SO₄) = ½ · n(H₃O⁺).
Lösung (erst nach eigenem Versuch öffnen!)
n(OH⁻) = 0,002 mol; n(H₂SO₄) = 0,001 mol; c = 0,04 mol/L
