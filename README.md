# sol-hilfen

Gestufte Hilfen zu SOL-Lerneinheiten Biologie (FOS BOS Würzburg).
Material: M. Oster-Brandt, FOS BOS Würzburg (erstellt mit KI-Unterstützung).

## Übersicht aller Hilfen

`index.html` zeigt alle Hilfeseiten nach Fach, Lehrplanthema, Klasse und Unterrichtsform (SOL / normaler Unterricht).
Die Inhalte stehen in `katalog.json`. Neue Hilfen: Seite in einen eigenen Ordner legen (z. B. `oekologie/`)
und in `katalog.json` eine Einheit mit Fach, Klasse, Lehrplanthema, Form (`SOL` oder `Unterricht`) und den Modulen ergänzen.
Die Adressen bestehender Seiten (QR-Codes!) nie ändern.
